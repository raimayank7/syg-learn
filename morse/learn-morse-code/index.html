How to learn Morse code: a practical method

This is our own advice.

Learn by sound, not by the picture

Think of A as "di-dah", not as a dot and a dash on paper. Use the player on the translator page to hear each character and say it aloud.

A few characters at a time

  1. Start with E, T, I, M, A, N: all one or two signals.
  2. Add S, O, H, R, then the rest of the letters, a handful a day.
  3. Learn the figures last, using their rule: 1 to 5 start with dots, 6 to 9 with dashes.

Short daily sessions

Ten minutes a day beats an hour a week. Use the trainer in both directions: read a signal and name the character, and see a character and pick its signal.

Keep the gaps right

Use the spacing rules (1, 3 and 7 dots) so that the letters do not run together. See how the timing works.

When to add words

Once you know most letters, send short words with the translator and play them back. Start slowly and increase speed only when you are right nearly every time.

Source: Recommendation ITU-R M.1677-1, "International Morse code" (10/2009), ITU Radiocommunication Sector, saved from the ITU site and read on 14 November 2026. It is the edition we read; we could not check the ITU site for a later edition, so check it before treating this one as current. We write dots as · and dashes as −.
