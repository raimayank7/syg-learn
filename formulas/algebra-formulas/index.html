Algebra formulas: identities and quadratics

These identities hold for every pair of numbers. Each card shows both sides, so you can type any numbers and see that they come out equal. For the quadratic formula the calculator gives the discriminant and both roots.

(a + b) squared

(a + b)² = a² + 2ab + b²

Expanding brackets and finding squares such as 103² = (100 + 3)².

Worked example: With a = 7, b = 3: (a + b)² = 100; a² + 2ab + b² = 100.

(a − b) squared

(a − b)² = a² − 2ab + b²

Expanding brackets and finding squares such as 98² = (100 − 2)².

Worked example: With a = 7, b = 3: (a − b)² = 16; a² − 2ab + b² = 16.

Difference of two squares

a² − b² = (a + b)(a − b)

Factorising, and quick products such as 52 × 48 = 50² − 2².

Worked example: With a = 52, b = 48: a² − b² = 400; (a + b)(a − b) = 400.

(a + b) cubed

(a + b)³ = a³ + 3a²b + 3ab² + b³

Expanding cubes of sums.

Worked example: With a = 4, b = 3: (a + b)³ = 343; a³ + 3a²b + 3ab² + b³ = 343.

Sum of two cubes

a³ + b³ = (a + b)(a² − ab + b²)

Factorising a sum of cubes.

Worked example: With a = 5, b = 2: a³ + b³ = 133; (a + b)(a² − ab + b²) = 133.

Difference of two cubes

a³ − b³ = (a − b)(a² + ab + b²)

Factorising a difference of cubes.

Worked example: With a = 5, b = 2: a³ − b³ = 117; (a − b)(a² + ab + b²) = 117.

Roots of a quadratic equation

For ax² + bx + c = 0 (a ≠ 0): x = (−b ± √(b² − 4ac)) / 2a, and the discriminant is D = b² − 4ac

Solving quadratic equations. If D is negative there are no real roots.

a cannot be 0.

Worked example: With a = 1, b = -5, c = 6: Discriminant D = 1; Root with + = 3; Root with − = 2.

Arithmetic progression: nth term and sum

nth term: aₙ = a + (n − 1)d. Sum of n terms: Sₙ = n/2 × [2a + (n − 1)d]

Patterns with a constant difference d, such as 3, 7, 11, 15, ...

Worked example: With First term a = 3, Common difference d = 4, Number of terms n = 10: nth term = 39; Sum of n terms = 210.

Geometric progression: nth term and sum

nth term: aₙ = a × rⁿ⁻¹. Sum of n terms (r ≠ 1): Sₙ = a(rⁿ − 1) / (r − 1)

Patterns with a constant ratio r, such as 2, 6, 18, 54, ...

r cannot be 1.

Worked example: With First term a = 2, Common ratio r = 3, Number of terms n = 5: nth term = 162; Sum of n terms = 242.

Remember by using

  • Try each identity with 1 and 2 before you trust your memory of it.
  • The sign in the middle of (a − b)² is minus, but b² is always plus.
  • If the discriminant is negative, the quadratic has no real roots and the calculator will say so.
