About the dinosaur data

Every fact about a dinosaur on this site comes from the Paleobiology Database. Here is exactly what we took and how we checked it.

Source and licence

The Paleobiology Database (paleobiodb.org) is a public database of fossil records. Its data are licensed under CC BY 4.0, which means we may use them if we credit them. We downloaded the list of dinosaur genera and the table of time intervals from its data service (version 1.2) on 14 November 2026. We do not claim the Paleobiology Database approves this site.

What each field means

  • Accepted name: the name the database treats as the correct name of the genus.
  • Family: the group of closely related genera that the genus is placed in.
  • Earliest and latest interval: named slices of the geologic time scale where the genus first and last appears in the database.
  • First and last appearance: the oldest and youngest possible ages for those two events, in million years ago.
  • Fossil records: how many records the database holds for the genus.
  • Diet: a label that the database gives for some genera. It is an interpretation.

How the 56 genera were chosen

We started from the dinosaur genera with the most fossil records and kept those with complete data. We dropped names the database treats as older names of another genus, names with a bird order, and families that are footprints or eggs (their names contain "oolith" or "pod"). We also dropped any genus whose earliest interval or latest interval did not match its ages. Then we kept the 56 with the most records. This is a choice of well-documented genera and not a list of all dinosaurs.

What the data does not have

The database gives no length, height or weight for these genera, and nothing about colour, sound or behaviour. So we show none. Two genera, Lufengosaurus and Massospondylus, have no diet label: their pages say "not given in the data".

Checks on every build

  • Every genus has the same required fields and no empty field is shown.
  • The oldest possible first age is older than the youngest possible last age, and each interval agrees with the ages.
  • The chart and quiz code is run in Node and each answer is worked out again in Python from the saved data.
  • Every finished page is read back and each number is compared with the data using a second program.

Because the database keeps improving, a later download can show different names or ages.

Data: The Paleobiology Database (paleobiodb.org), data service version 1.2, licence CC BY 4.0, downloaded 14 November 2026. We chose and re-worded the data and wrote the explanations; the Paleobiology Database does not endorse this site. This site is independent and not affiliated with the Paleobiology Database, any museum, university or film.

Scientists revise names, ages and groups as they learn more, so a later download of the database can differ from this page. Where the database gives no value for something, this site says "not given in the data" and does not fill it in.
