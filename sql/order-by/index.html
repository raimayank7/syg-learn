Sorting with ORDER BY

A database does not promise to return rows in any particular order. They may come back in the order they were stored today and in another order tomorrow. If the order matters to you, say so with ORDER BY.

Sorting by one column

ORDER BY goes at the end of the query, after WHERE if there is one.

SELECT name, price
FROM products
ORDER BY price;

Sorting by more than one column

List several columns. The result is sorted by the first. Rows that tie on the first are sorted by the second, and so on.

SELECT name, category, price

ORDER BY category, price DESC;

Filtering, then sorting

WHERE comes before ORDER BY. The database first picks the rows, then sorts them.

SELECT name, price
FROM products
WHERE category = 'Home'
ORDER BY price;

Sorting by a calculation or an alias

You can sort by something worked out. And unlike WHERE, ORDER BY can use an alias, because sorting happens after the columns have been named.

SELECT name, price * stock AS stock_value
FROM products
ORDER BY stock_value DESC;

Sorting by position

You may give the number of a column in the SELECT list instead of its name. ORDER BY 2 means "sort by the second column".

SELECT name, salary
FROM employees
ORDER BY 2 DESC;

How text is sorted

Text is compared character by character. Two things can surprise you.

  • Case. In SQLite and PostgreSQL, capital letters sort before small letters by default, so "Zebra" comes before "apple". MySQL and SQL Server usually ignore case. In our data every name starts with a capital, so you will not notice.
  • Numbers stored as text. If a column holds text such as '9', '10' and '100', it sorts as text: '10', '100', '9'. Numbers should be stored in number columns.

Ties have no fixed order

If two rows have the same value in every sort column, the database may return them in either order. When you need the same order every time, for example when showing results a page at a time, add a column that is unique, such as id, at the end of the ORDER BY.

SELECT name, salary
FROM employees
ORDER BY salary DESC, id;
