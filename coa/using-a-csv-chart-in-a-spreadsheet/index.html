Using your chart of accounts CSV in a spreadsheet

The downloaded file is a plain CSV: one account per line, with a heading line and seven columns: Code, Account, Class, Normal balance, Appears in, Contra account and Description. Any spreadsheet program can open it. The file is made in your browser and starts with a marker so that spreadsheets read names correctly.

Opening it

  1. Find the file in your downloads folder. Its name starts with chart-of-accounts.
  2. Open it in your spreadsheet program, or use its import or open command and choose comma as the separator.
  3. If a program shows odd characters, choose UTF-8 as the text encoding when you import.

Working with it

  • Keep the codes as they are. Codes such as 1000 are numbers; if you want to add leading zeros, format the column as text first.
  • Sort by Code to keep accounts in statement order.
  • Filter by Class to see only expenses or only assets.
  • Add accounts as new lines, with a code in the right range and the right class. Check the Normal balance column against the class: assets and expenses debit, the rest credit, unless it is a contra account.

Giving it to others

Save a copy before you change anything. If you use accounting software, ask its help pages which columns and code formats it can import: some need only code and name, and some want a type from their own list. Our "Class" column uses plain words: Asset, Liability, Equity, Income and Expense.

These lists and the numbering are our own examples. They are not an official, statutory or board-approved chart, and they claim to follow no accounting standard or tax rule. Rules differ between places and organisations, so check what your own accountant, course, lender or governing body requires.
