Financial ratio analyzer

Type the figures and read sixteen ratios, each with its formula.

How to use it

  1. Type the figures from the profit and loss account and the balance sheet, in one currency and unit.
  2. Read the ratios that appear. Boxes you leave empty only switch off the ratios that need them.
  3. Use the sample figures to see how it works, then clear them and type yours.
  4. Read the guides on liquidity, profitability and leverage and efficiency.

What the tool does not do

  • It does not tell you whether a ratio is good or bad: that depends on the industry and on the lender or exam.
  • It uses closing figures, not averages of the opening and closing balances.
  • It does not check that your balance sheet balances.

These are common textbook definitions, using the closing figures you type and 365 days a year. Books and companies differ (some use average balances), so use the definition your course or lender uses. We give no target values and no advice on any business.
