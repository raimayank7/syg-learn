How we check the book guides

Every guide on this site was written by us in our own words. We did not copy any study-guide site, and we did not use the introductions or notes of modern editions. We read the plain text of each book from Project Gutenberg, and a computer program checks the guide against that text every time the site is built.

What the program checks

  1. The chapter headings found in the downloaded text must match the chapter list in the guide: same number, same order, same titles.
  2. Any chapter count written on a page must equal the count found in the text.
  3. Every character named in a guide, and every name used in a chapter summary, must appear in the text (and, for a chapter summary, in that chapter).
  4. Each short quotation (one per book, under fifteen words) must appear word for word in the text.
  5. Every quiz answer must occur in the chapter the question cites.

If any check fails, the site is not built. A passing check proves that a name or answer is in the book. It does not prove that our reading of the story is right, so read the book too.

What we do not say

We say nothing about the authors beyond the name Project Gutenberg prints, and we give no dates or biography we have not verified. Exam boards differ in what they ask: follow your own syllabus and your teacher.
