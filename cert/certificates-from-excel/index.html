Certificate Maker

Make certificates from an Excel or Google Sheets list

You do not need to import a file. Copy from the spreadsheet and paste.

Steps

  1. In Excel or Google Sheets, put the names in the first column. Put a personal reason in the second column if some people need their own.
  2. Select the cells and copy them (Ctrl+C).
  3. Click in the names box on the certificate maker and paste (Ctrl+V). A second column arrives after a tab, which is what the tool expects.
  4. Check the number of certificates shown under the box.
  5. Print.

Tips

  • Remove empty rows and headings from the copied cells; the heading row would become a certificate.
  • Up to 200 names are used at one time. For more, do two lists.
  • Names over 60 characters are cut, so check very long names.

If something looks wrong

If a reason does not appear, check that the cells were copied from two columns side by side, with nothing between them. If a name shows two lines of text, it had a line break inside the cell.
