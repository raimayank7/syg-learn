How to add and subtract fractions step by step

This is our own explanation of a standard method.

The key idea

You can add things only if they are the same size. 1/4 and 1/6 are pieces of different sizes, so first cut both into the same size of piece.

The steps

  1. Find a common denominator: a number that both bottoms divide into. The smallest is best.
  2. Change each fraction so that it has this denominator, multiplying top and bottom by the same number.
  3. Add or subtract the tops. Keep the bottom.
  4. Simplify by dividing top and bottom by their HCF.

Example

1/4 + 1/6. The smallest common denominator of 4 and 6 is 12. 1/4 = 3/12 and 1/6 = 2/12. Add the tops: 3 + 2 = 5, so 5/12.

Common mistakes

MistakeWhy it is wrong
Adding the tops and the bottoms: 1/4 + 1/6 = 2/10The pieces are different sizes; the answer 2/10 is smaller than 1/4 itself
Forgetting to change the top when you change the bottomThe fraction would then have a different value
Not simplifyingThe answer is right but not in its simplest form
