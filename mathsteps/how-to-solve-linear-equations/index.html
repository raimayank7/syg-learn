How to solve linear equations step by step

This is our own explanation of a standard method.

The balance idea

An equation is a balance. Whatever you do to one side, you must do to the other, so that it stays balanced.

The steps for a x + b = c

  1. Undo the addition or subtraction: take b from both sides, so a x = c − b.
  2. Undo the multiplication: divide both sides by a, so x = (c − b) / a.
  3. Check: put x back in the first equation. Both sides must be equal.

Example

2x − 7 = 9. Add 7 to both sides: 2x = 16. Divide by 2: x = 8. Check: 2 × 8 − 7 = 9.

Why undo the addition first

In 2x − 7, the 2 multiplies x and then 7 is taken away. To undo the steps, go backwards: add 7 first, then divide by 2.

Common mistakes

  • Changing only one side.
  • Moving a number and forgetting to change its sign.
  • Not checking the answer.
