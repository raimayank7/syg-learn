Maths Steps

Linear equation solver with steps: ax + b = c

Type a, b and c and read the solution step by step.

How to use it

  1. Write your equation as a x + b = c. For 3x + 5 = 20, a = 3, b = 5 and c = 20.
  2. Type a, b and c in the boxes.
  3. Read x and the steps; the last step checks the answer.

A worked example

3x + 5 = 20. Take 5 from both sides: 3x = 15. Divide both sides by 3: x = 5. Check: 3 × 5 + 5 = 20.

Limits

  • a cannot be 0, or there is no x to find.
  • Answers that are not whole numbers are shown as fractions, such as x = 3/2.
  • Equations with x on both sides: first collect x on one side, then use this tool.

The explanations here are our own, and the answers are checked by program against separate code, but follow the method your teacher asks for in an exam. Whole numbers only, up to 1,000,000.
