How this set works

Ten four-option questions a round on moles, molarity, pH, dilution, oxidation numbers and first-order decay. Questions are made new each time. A right answer scores +4, a wrong one −1 and a skipped one 0, as in the NTA bulletin. After each answer you see the working.

These questions practise the numerical side of physical and inorganic chemistry: moles from masses, molarity, dilution, pH of strong acids and bases, oxidation numbers and first-order half-life. Atomic masses are given where needed. For the topics behind each question, see the chemistry syllabus guide.

What the questions test

The set draws on these topics. Each row says what is asked and the slip that most often goes with it.

How to review a round

In chemistry calculations, most marks are lost before any arithmetic: a wrong molar mass, millilitres not converted to litres, or a concentration used where an amount was needed. After each wrong answer, write the formula, the molar masses and the units of each quantity, then see where the chain broke.

For pH and oxidation number questions, write the definition first (pH is minus the log of the hydrogen ion concentration; oxidation numbers in a neutral compound add to zero). The chemistry syllabus guide lists the units behind each question.
