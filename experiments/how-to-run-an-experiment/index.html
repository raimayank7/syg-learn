How to run a home science experiment with children

Adult supervision needed. An adult must be nearby for every experiment on this site, from start to finish. Children should never do the steps marked Adult alone. If anything feels unsafe, stop.

An experiment is a question you ask by doing. These habits help children think like scientists, and they cost nothing.

1. Ask a question

Start with something the child wants to know: "Will it sink?" Let them put the question in their own words.

2. Predict

Ask for a guess before you start, and write it down. A wrong guess is not a failure, because it is the part that teaches the most.

3. Change only one thing

If you want to know whether warm water dissolves sugar faster, use the same amount of water and the same sugar in each cup and change only the warmth. This is called a fair test.

4. Look closely and record

Draw what you see, count, or time it. A small table is enough. The record sheet can be printed.

5. Repeat

Do it two or three times. If the answer is the same each time, you can trust it more. If it changes, ask why.

6. Explain

Ask "Why do you think that happened?" before you read the explanation. Then compare it with the "Why it works" section. It does not matter if the child's idea was different.

For adults

  • Let the child do the steps that are safe for them, even if it is slower.
  • Answer "I do not know, let us find out" when you do not know.
  • Do not hurry. Ten calm minutes are enough.
  • Stop when interest fades.

These experiments are our own writing, using only facts from school textbooks. They are not medical or safety certification, and an adult is responsible for judging whether an experiment is safe for a particular child, home and set of materials, including allergies.
