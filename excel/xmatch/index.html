XMATCH function in Excel

XMATCH returns the position of a value in a range, with exact match as the default and a choice of search direction.

XMATCH is the newer form of MATCH, introduced together with XLOOKUP. It returns a position in the same way, and fixes the things that made MATCH risky. It is in Excel 2021 and Microsoft 365, and not in earlier versions.

Syntax

=XMATCH(lookup_value, lookup_array, [match_mode], [search_mode])
ArgumentWhat it is
lookup_valueThe value to look for.
lookup_arrayA single row or column to search.
match_mode0 exact match (the default), -1 exact or next smaller, 1 exact or next larger, 2 wildcard match.
search_mode1 first to last (the default), -1 last to first.

Examples

Each result below is what Excel itself showed for the formula on the sample sheet.

  • =XMATCH("Ravi",B2:B13)
    Result: 2

    The first row on which Ravi appears: the 2nd sale in the list.

  • =XMATCH("Ravi",B2:B13,0,-1)
    Result: 10

    Search mode -1 starts from the bottom: Ravi's most recent sale is the 10th in the list.

  • =INDEX(F2:F13,XMATCH("Ravi",B2:B13,0,-1))
    Result: 1500

    With INDEX: the amount of Ravi's latest sale.

  • =XMATCH(1000,F2:F13,1)
    Result: 1

    Match mode 1: there is no sale of exactly 1000, so the next larger amount is used, 1200, which sits in position 1.

  • =XMATCH("B*",D2:D13,2)
    Result: 3

    Wildcard mode: the first product that starts with B.

What is different from MATCH

  • Exact match is the default. With MATCH you must remember to type 0. With XMATCH you get an exact match unless you ask for something else.
  • It can search from the end. Search mode -1 returns the last match, not the first. In a list kept in date order, that is the latest entry, which is very often the one you want.
  • Approximate matches do not need a sorted list. MATCH demands a sorted range for its approximate modes. XMATCH with match mode -1 or 1 checks every item and finds the nearest one below or above.
  • The numbers mean something else. In MATCH, match type 1 means "next smaller". In XMATCH, match mode 1 means "next larger" and -1 means "next smaller". Take care when converting old formulas.

Match modes

match_modeMeaning
0exact match
-1exact match, or the next smaller item
1exact match, or the next larger item
2wildcard match, with * and ?

Typical uses

The latest entry for a person or product. Pair it with INDEX, as in the third example. Before XMATCH this needed an awkward array formula.

The nearest value in an unsorted list. =XMATCH(target, range, -1) finds the closest value at or below a target wherever it sits.

Position in a ranking. If a column of scores is sorted from highest to lowest, the XMATCH of a score is its place.

XMATCH or XLOOKUP?

If you want the value itself, XLOOKUP does it in one step. Use XMATCH when you need the position: to feed INDEX with a row and a column, to choose a column by its heading, or to test whether something is in a list with ISNUMBER(XMATCH(...)).

Common mistakes

  • #NAME? means the Excel version is too old for XMATCH. Use MATCH.
  • #N/A means nothing matched. Check for stray spaces and for numbers stored as text.
  • A two-dimensional range. As with MATCH, the lookup array must be one row or one column.

In Google Sheets

Google Sheets has XMATCH too, with the same arguments.
