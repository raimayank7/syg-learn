CBSE Class 12 board exam 2026-27: structure and grades

The 2026-27 senior secondary curriculum covers Classes XI and XII together. This page summarises what it says about Class XII and how the subject PDFs we read set the marks.

A composite course

The curriculum says Classes XI and XII are a composite course: a student takes in Class XI only the subjects they mean to continue in Class XII, offers a minimum of five or more subjects in Class XI and continues the same subjects in Class XII.

The Board Examination

  • The Board conducts annual examinations for Class XII, and the examination covers the entire syllabus of Class XII for each subject.
  • Assessment has theory, internal assessment or practical components, as the syllabus of each subject sets out.
  • Grades are on a 9-point scale in each elective subject, awarded by rank order of the passed students in eighth-parts, from A-1 to D-2 and E for essential repeat.
  • The curriculum says Board papers will have more questions based on real-life situations that need students to apply, analyse, evaluate and synthesise, but the competencies come from the prescribed syllabus and textbooks.

What the PDFs do not tell us

We did not find the pass marks for Class XII in the curriculum text we read, so this site does not state them for Class XII. Check CBSE notices and your school.
