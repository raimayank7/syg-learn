Linux and Mac commands

sort, uniq, wc and cut: work with lines and columns

Text files with one record per line, such as logs, lists and CSV files, can be sorted, counted and summarised with a few small commands. They never change the original file. They print a result, which you can view or send to a new file.

wc: count

With no option, wc prints lines, words and bytes. -l counts lines, -w words and -c bytes. Given several files, it totals them.

sort

Alphabetical by default. The useful options:

OptionEffect
-rreverse
-nsort as numbers
-hunderstand sizes such as 2K and 1G
-udrop duplicate lines
-k 2sort by the second field
-t ,fields are separated by commas
-fignore case

Numbers need -n. Without it they sort as text, where 100 comes before 9.

Sorting by a column

-t names the separator and -k the field. This sorts the marks file by the second column, as numbers, highest first. tail -n +2 leaves out the heading row.

Add | head -n 3 for the top three.

uniq: repeated lines

uniq removes lines that repeat the line before. It only compares neighbours, so the input must be sorted first.

The first result still has repeats, because equal lines were not next to each other. After sorting, each value appears once.

uniq -c counts how many times each line occurred. Followed by a numeric sort, it gives a frequency table, one of the most used recipes on the command line.

uniq -d shows only the lines that are repeated, and uniq -u only those that are not.

cut: columns

cut takes part of each line. -d gives the separator and -f the fields wanted.

-f 1,3 takes fields 1 and 3, and -f 2- everything from field 2 onwards. -c cuts by character position instead.

cut cannot cope with separators that vary, such as several spaces. For that, awk is the tool: awk '{print $2}' prints the second word of each line, whatever the spacing.

tr: change characters

tr replaces or deletes characters in what it reads.

In order: small letters to capitals, commas to line breaks, and dashes deleted.

Adding up a column

There is no "sum" command, but awk adds a column in one line.

-F , sets the separator. For each line the second field is added to a running total, and the total is printed at the end.

Putting them together

How many different words are in a file?

tr turns each space into a line break, giving one word per line. sort -u removes duplicates, and wc -l counts.

Saving the result

These commands print. To keep the result, send it to a different file.

Danger. sort file.txt > file.txt wipes the file. The shell empties it before sort reads it. Write to a new name, or use sort -o file.txt file.txt, which is made for sorting a file in place.

CSV files with awkward data

cut and sort split on every comma. Real CSV files sometimes have commas inside quoted values, such as "Verma, Asha". These tools will split that in the wrong place. For such files use a spreadsheet, or a tool that understands CSV properly.
