Linux and Mac commands

echo, variables and PATH

The shell keeps named values called variables. Some are yours, made on the spot. Others, the environment variables, are handed to every program you start, and tell it things such as where your home folder is and where to look for commands.

echo

echo prints its arguments. With > it writes them to a file, and with >> it adds to the end of one.

Danger. A single > replaces the whole file without asking. Use >> to add.

Variables

Set a variable with a name, an equals sign and a value, with no spaces round the equals sign. Read it with a dollar sign.

city = Ludhiana, with spaces, is an error: the shell looks for a command named city.

Quotation marks

FormEffect
"double"variables inside are replaced by their values
'single'everything is taken literally

The result of a command

$( ) runs a command and puts its output in place.

The environment

These are set for you when you sign in.

VariableHolds
$HOMEyour home folder
$USERyour user name
$PWDthe current folder
$SHELLthe shell program you are using
$PATHthe folders searched for commands
$LANGyour language setting

env or printenv lists every environment variable.

export

A plain variable belongs to the shell only. export passes it on to the programs you start from that shell.

Variables set this way last until you close the terminal.

PATH

When you type a command, the shell looks for a program of that name in each folder listed in PATH, in order, and runs the first one found.

The folders are separated by colons. If a command is in none of them, you get:

"Command not found" means it is not on the PATH. The program may or may not be installed.

Which program runs?

which prints the full path of the program a command would start. type also knows about commands built into the shell and about aliases.

Danger. Always include $PATH itself in the new value. export PATH="$HOME/bin", without it, replaces the whole list, and ordinary commands such as ls stop being found. If that happens, close the terminal and open a new one: the change lasted only for that session. If the mistake is in the start-up file, edit the file using a command's full path, such as /usr/bin/nano ~/.zshrc.

Aliases

An alias gives a short name to a longer command.

Put aliases in the start-up file to keep them. alias on its own lists them, and unalias ll removes one.

A first script

A script is a text file of commands. The first line names the shell that should run it.

Save it as hello.sh, make it runnable with chmod +x hello.sh, and run it with ./hello.sh. See chmod.

Clearing the screen

clear, or Ctrl + L, clears the terminal.

The Windows equivalents are echo, set and PATH.
