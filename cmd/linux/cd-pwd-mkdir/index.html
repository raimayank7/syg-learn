Linux and Mac commands

cd, pwd, mkdir and rmdir: move around and make folders

The terminal is always "in" one folder, called the working directory. Commands act there unless you give another path. pwd tells you where you are, cd takes you somewhere else, and mkdir makes new folders.

Where am I?

pwd stands for print working directory. Get into the habit of running it before any command that deletes or overwrites.

Moving

Two dots mean the folder above.

Paths

A path is a route to a file or folder. Linux and the Mac separate its parts with a forward slash.

PathMeaning
/the root: the top of the whole system
/home/ashaan absolute path, starting from the root
photosa relative path, starting from where you are
.this folder
..the folder above
../oldup one, then into old
~your home folder
~/DocumentsDocuments inside your home folder

On Linux, home folders live in /home. On a Mac they live in /Users.

Shortcuts for cd

CommandGoes to

cd - is worth remembering. It flips between two folders, however far apart.

Capital letters matter

On Linux, Photos and photos are two different names. Typing the wrong case gives "No such file or directory".

The Mac's usual file system ignores case here, but scripts written on a Mac then fail on Linux, so type names exactly.

Press Tab after the first few letters and the shell completes the name, with the right case.

Making folders

To make a folder inside a folder that does not exist yet, add -p. It creates every missing level and does not complain if the folder is already there.

The first command failed because reports/2026 did not exist. With -p it worked.

Several folders can be made at once: mkdir jan feb mar.

Removing folders

rmdir removes a folder only if it is empty.

The refusal for photos is a protection. To remove a folder that has things in it, the command is rm -r, which is powerful and dangerous. It has a page of its own.

Names with spaces

A space separates arguments, so a name containing one must be quoted or escaped.

Many people avoid the problem by using dashes or underscores in names: tax-papers.

Seeing the structure

ls -R lists everything below. A clearer picture comes from the tree command, which is not installed by default on every system. find . -type d lists every folder below the current one, and works everywhere.

Opening the folder in a window

  • On a Mac: open .
  • On most Linux desktops: xdg-open .

Going the other way on a Mac, dragging a folder from Finder onto the Terminal window types its path for you.

Common mistakes

  • "No such file or directory." Misspelling, wrong case, or the folder is not where you think. Run ls.
  • "Not a directory." You tried to cd into a file.
  • "Permission denied." The folder belongs to someone else or to the system.
  • Forgetting where you are. Run pwd.

The Windows equivalents are cd, mkdir and rmdir.
