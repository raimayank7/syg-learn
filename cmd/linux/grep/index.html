grep: search inside files

grep prints the lines of a file that contain a word or pattern. It answers "where does this appear?" for one file or ten thousand. It reads and never changes anything.

The basic search

The pattern comes first, then the file.

The everyday options

OptionEffect
-iignore capital and small letters
-nshow line numbers
-ccount matching lines
-vinvert: show lines that do not match
-wmatch whole words only
-llist only the names of files that contain a match
-rsearch all files in a folder and below
-A 2, -B 2also show 2 lines after, or before, each match
-Eextended patterns, such as a|b for either

A phrase

A pattern with spaces needs quotation marks.

Several files

Give several names or a wildcard. Each match is shown with its file name.

A whole folder

-r searches every file below a folder. Adding -l gives just the file names, and -n the line numbers.

The dot means "the current folder". Limit the search to certain files with --include:

Whole words

Without -w, the pattern matches anywhere, even inside longer words.

The first counts lines containing "port", which includes "report". The second counts only the word by itself.

Either of two words

-E switches on extended patterns, where a bar means "or".

Context

When a match alone is not enough, show the lines around it.

Patterns

grep understands regular expressions. The most useful pieces:

PatternMatches
^wordlines that start with word
word$lines that end with word
.any one character
[0-9]any digit
[A-Z]any capital letter
a*a repeated none or more times
^$empty lines

Put patterns in quotation marks, so that the shell does not try to interpret the special characters itself. To search for text that contains these characters literally, use -F, for fixed text: grep -F "a.b" file.

Searching the output of other commands

grep reads from a pipe as well as from files. This is how it is used most.

Common uses: ps aux | grep firefox to find a running program, history | grep ssh to find an earlier command, and dmesg | grep -i usb to look at system messages.

Counting and combining

-c counts lines. To count matches in many files and total them, pipe through wc -l.

Saving the result

Speed and binary files

grep is fast. On very large folders, exclude what you do not need with --exclude-dir, such as --exclude-dir=.git. If it reports "Binary file matches", the file is not text. -I skips such files.

Common mistakes

  • The file and pattern the wrong way round. Pattern first.
  • No quotation marks round a pattern with spaces or symbols.
  • Forgetting -i and missing "Error" while searching for "error".
  • Forgetting -r when pointing at a folder: "Is a directory".
  • A search that hangs. With no file named, grep waits for you to type input. Press Ctrl + C.

The Windows equivalent is findstr.
