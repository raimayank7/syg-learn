Linux and Mac commands

ls: list the files in a folder

ls lists what is in a folder. It is the command you will type more than any other, and it changes nothing, so it is safe to experiment with.

The plain listing

Just names, in alphabetical order. On most systems folders and files are shown in different colours.

The long listing

-l gives one line per item, with details.

Reading one line from the left:

PartMeaning
-rw-r--r--the type and the permissions. A leading d means a folder, - an ordinary file
1the number of links, which you can ignore
asha ashathe owner and the group
51the size in bytes
Nov 1 15:00when it was last changed
notes.txtthe name

The permission letters are explained on the page about chmod.

Hidden files

Names that begin with a dot are hidden from a plain ls. Settings files are usually named this way. -a shows all.

The entries . and .. mean this folder and the one above it.

Sizes people can read

-h, with -l, shows sizes as K, M and G instead of plain bytes.

Newest first

-t sorts by time, newest first. -r reverses any order. Together, -ltr puts the most recently changed file at the bottom, next to the prompt, which is where you want it in a long folder.

Sort by size with -S, largest first.

Another folder, and patterns

A star matches any run of characters, and a question mark exactly one. The shell expands the pattern before ls runs, so ls *.txt really receives the list of matching names.

Everything below

-R lists this folder and every folder inside it.

Folders marked

-F adds a slash after folder names, which helps when colours are not available. -d lists a folder itself instead of its contents.

Combining options

Single-letter options can be joined after one dash. ls -lah is the favourite of many people: long, all, human-readable.

OptionEffect
-llong listing
-ainclude hidden files
-hhuman-readable sizes
-tsort by time, newest first
-Ssort by size, largest first
-rreverse the order
-Rinclude subfolders
-Fmark folders with a slash
-1one name per line

Counting files

Pipe the list into wc -l to count lines.

When a file is not there

The message means exactly what it says. Check the spelling, remember that capital letters matter on Linux, and make sure you are in the folder you think you are in with pwd.

Names with spaces

Put the name in quotation marks, or put a backslash before each space: ls "My Documents" or ls My\ Documents. Pressing Tab after the first letters completes a name correctly, spaces included.

On a Mac

The Mac's ls is a slightly different version from the one on Linux. The options on this page work on both. Colours are switched on with ls -G on a Mac and ls --color on Linux.

The Windows equivalent is dir.
