Linux and Mac commands

cat, less, head and tail: read text files

Four small commands for looking inside text files without opening an editor. Between them they handle everything from a three-line note to a log of a million lines.

cat: print the whole file

Good for short files. -n numbers the lines.

The name comes from "concatenate": given several files, cat prints them one after another, which joins them.

Sent into a new file with >, that makes a combined file: cat part1.txt part2.txt > whole.txt.

Danger. cat a.txt b.txt > a.txt does not append b to a. The shell empties a.txt before cat reads it, and the contents are lost. Write to a different file name.

less: one screen at a time

For anything longer than a screen, use less. It opens the file in a viewer and waits for keys. Shown here without being run:

KeyAction
Spacenext screen
bprevious screen
Down arrow or Enternext line
ggo to the start
Ggo to the end
/wordsearch forward for a word
nnext match
qquit

less reads only as much of the file as it shows, so it opens huge files instantly. It never changes the file. If you find yourself stuck in a screen full of text with a colon at the bottom, you are in less: press q.

head: the first lines

Without -n, head shows ten lines. It is the quick way to see what kind of file something is, or to read the heading row of a CSV.

tail: the last lines

Logs grow at the bottom, so the end is where the news is.

tail -n +2 means "from line 2 onwards", which skips a heading row.

Following a file as it grows

tail -f keeps the file open and prints new lines as they are written. It is how people watch a log while a program runs. Press Ctrl + C to stop.

Not for every file

These are for text. A picture, a PDF or a program printed with cat fills the screen with symbols and can leave the terminal behaving oddly. If that happens, type reset and press Enter, even if you cannot see what you type. To find out what a file is before opening it, use file name.
