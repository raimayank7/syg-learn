Linux and Mac commands

tar, zip and unzip: archives

An archive puts many files and folders into one file, usually compressed, for sending or for safe keeping. On Linux and the Mac, two formats cover nearly every case: .tar.gz, the native one, and .zip, which every system can open.

tar: making an archive

The letters after the dash are separate options.

LetterMeaning
ccreate an archive
xextract from an archive
tlist the contents
zcompress with gzip
fthe next word is the archive's file name
vverbose: name each file as it is handled

So -czf reads "create, gzip, file". The archive name comes straight after f, and then the things to put in it. The originals are left untouched.

Several files and folders can go in one archive.

Looking inside without unpacking

Always list an archive before extracting one you did not make.

Extracting

-C names the folder to unpack into. Without it, files are unpacked into the current folder.

To take out a single item, name it after the archive: tar -xzf backup.tar.gz notes.txt.

Danger. Extracting overwrites existing files of the same name without asking. An archive whose paths do not begin with a single folder scatters its files into wherever you are. List the contents first, and unpack into a new, empty folder with -C.

Which compression?

EndingCompressiontar letter
.tarnone, just bundled(none)
.tar.gz or .tgzgzip: quick, the usual choicez
.tar.bz2bzip2: smaller, slowerj
.tar.xzxz: smallest, slowestJ

Modern tar works out the compression by itself when extracting, so tar -xf archive.tar.xz is enough for any of them.

Remembering the letters

Three patterns cover almost everything:

  • Create: tar -czf name.tar.gz things
  • List: tar -tzf name.tar.gz
  • Extract: tar -xzf name.tar.gz

Only the first letter changes: c, t, x.

zip and unzip

Use .zip when the archive is going to someone on Windows, or when you are not sure what they use.

  • zip -r includes the contents of folders. Without -r, a folder is added empty.
  • unzip -l lists the contents.
  • unzip -d names the folder to unpack into.

zip -e asks for a password and encrypts the archive. The standard zip encryption is weak, so do not depend on it for anything sensitive.

zip and unzip are present on the Mac and on most Linux systems. Where they are missing, the package manager installs them.

A dated backup

Putting the date in the name keeps backups apart and in order.

The part in $( ) runs the date command and inserts its result, giving a name such as documents-2026-11-12.tar.gz.

Leaving things out

--exclude skips files that match a pattern. Put it before the folder name.

gzip on its own

gzip file compresses a single file and replaces it with file.gz. gunzip file.gz reverses it. gzip -k keeps the original. zcat and zless read a compressed text file without unpacking it.

Checking an archive

A backup that cannot be read is no backup. tar -tzf archive.tar.gz > /dev/null reads the whole archive and reports any damage. For archives that matter, list them after making them, and now and then try restoring one into a spare folder.

Common mistakes

  • Putting f anywhere but last in the group of letters. The word after f is taken as the file name, so -cfz makes an archive called z.
  • Forgetting -r with zip.
  • Extracting into the wrong folder.
  • Making the archive inside the folder being archived, so that it tries to include itself.

On Windows 10 and 11, tar is built in and works the same way in the Command Prompt.
