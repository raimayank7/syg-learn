The differences that catch people out

Path separatorbackslash: C:\Users\ashaforward slash: /home/asha

Capital letters in namesignoredmatter on Linux; usually ignored on a Mac
Variables%NAME%$NAME
Wildcard for "all files"*.* or **

Home folder%USERPROFILE%~

The last line explains some surprises. On Linux, rm *.txt is turned into rm a.txt b.txt by the shell before rm starts. On Windows, del *.txt passes the pattern to del, which does its own matching.

Text files moved from Windows to Linux sometimes cause odd errors in scripts, because of the different line endings. Editors can save in either style, and the tool dos2unix converts a file.

Running Linux commands on Windows

There are three common ways.

  • Windows Subsystem for Linux (WSL) runs a real Linux system inside Windows. Open a Command Prompt as administrator and run wsl --install.
  • Git Bash, which comes with Git for Windows, provides the Bash shell and the common Linux tools, working on your Windows files. The Linux examples on this site were run with it.
  • PowerShell aliases make ls, cat, cp, mv, rm and pwd work, though with PowerShell's options, not Linux's.

Which column should I learn?

Learn the one for the system in front of you. The ideas, listing, moving, copying, searching, piping, are the same in all three. Once they are familiar in one, the others are a matter of looking up a name in the table above.
