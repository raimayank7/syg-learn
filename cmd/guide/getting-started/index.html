Getting started with the command line

The command line is a way of telling the computer what to do by typing, instead of clicking. It looks old-fashioned and is still in daily use, because for many jobs it is faster, it can be repeated exactly, and it works when nothing else does. This guide gets you from never having opened it to running your first commands safely.

Opening it

SystemProgramHow to open
WindowsCommand Promptpress the Windows key, type cmd, press Enter
WindowsPowerShell or Windows Terminalpress Win + X and choose Terminal
MacTerminalpress Cmd + Space, type terminal, press Enter
LinuxTerminalpress Ctrl + Alt + T on most desktops, or search for Terminal

A window opens with a line of text ending in a symbol and a blinking cursor. That line is the prompt. It is the computer waiting for you.

Reading the prompt

On Windows it looks like C:\Users\asha>. On Linux and the Mac, something like asha@pc:~$. Either way it tells you which folder you are in. The ~ on Linux and the Mac means your home folder. Everything you type happens in that folder unless you say otherwise.

How a command is built

A command is a line of words, run when you press Enter.

command options arguments

  • The command is the name of a program: dir, ls, copy.
  • Options change how it behaves. On Windows they begin with a slash, as in /b. On Linux and the Mac they begin with a dash, as in -l.
  • Arguments say what to act on, usually file or folder names.

Spaces separate the parts. That is why a name containing a space must go in quotation marks.

Keys that save effort

  • Tab completes a file or folder name after you type its first letters. Use it constantly. It prevents spelling mistakes.
  • Up arrow brings back the previous command, ready to run again or edit.
  • Ctrl + C stops a command that is running or has gone wrong.
  • Ctrl + L on Linux and the Mac, or cls on Windows, clears the screen.

Copying and pasting

In the Windows Command Prompt and Windows Terminal, Ctrl + C and Ctrl + V work, and a right-click pastes. On a Mac, use Cmd + C and Cmd + V. In Linux terminals, copy and paste are Ctrl + Shift + C and Ctrl + Shift + V, because Ctrl + C already means "stop".

When something goes wrong

Read the message. Command-line errors are short and usually exact.

MessageMeaning
"is not recognized as an internal or external command" (Windows), "command not found" (Linux, Mac)the command's name is misspelt, or the program is not installed or not on the PATH
"The system cannot find the file specified", "No such file or directory"wrong name, or you are in a different folder from the one you think
"Access is denied", "Permission denied"you are not allowed to do that to that file
nothing happens and the prompt does not returnthe command is waiting or still working: press Ctrl + C

Staying safe

The command line does exactly what it is told, at once, and mostly without asking. Four habits prevent nearly every accident.

  1. Know where you are before a command that changes anything. Look at the prompt, or run cd on Windows and pwd elsewhere.
  2. Look before you delete. List the files with the same pattern first.
  3. Do not paste commands you do not understand. Read our page on dangerous commands to see why.
  4. Practise on copies, in your practice folder.

Which command line?

Windows has two: the older Command Prompt, and PowerShell, which is more capable. The Windows pages on this site use the Command Prompt, since its commands are the ones most often quoted in instructions. The guide to PowerShell shows how they correspond. The Mac and Linux share almost all their commands, so one set of pages serves both.

Where to go next

Work through the pages in this order: listing files, moving between folders, copying and moving, reading text files, searching. By then the command line will feel like a tool and not a test.
