Get the details right

How to practise

Reading about commands teaches little. Make a folder called practice, put a few small text files in it, and try each command there as you read. Nothing in that folder matters, so nothing can go wrong. When a command surprises you, that is the lesson. Read the message it printed, and try again.

This is an independent learning site. It is not connected with Microsoft, Apple or any Linux distribution. Windows, macOS and other names belong to their owners. Try commands first in a practice folder, never on files you cannot afford to lose.
