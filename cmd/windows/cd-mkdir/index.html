Windows commands

cd, mkdir and rmdir: move between folders and make them

The Command Prompt is always "in" one folder, shown before the > sign. Commands act on that folder unless told otherwise. cd moves you to a different one. mkdir makes a new folder and rmdir removes one.

Where am I?

cd on its own prints the current folder.

Going into a folder, and back out

Two dots mean "the folder above this one". The prompt changes each time to show where you are.

Paths

A path is the route to a folder. There are two kinds.

  • A relative path starts from where you are: photos, or ..\old.
  • An absolute path starts from the drive: C:\Users\asha\demo\photos. It means the same place wherever you run it from.

Windows separates the parts of a path with a backslash.

You typeYou go to
cd photosthe photos folder inside the current one
cd ..the folder above
cd ..\..two levels up
cd \the top of the current drive
cd ..\oldup one level, then into old
cd C:\Usersthat exact folder

Pressing Tab after typing the first letters of a name completes it. Pressing Tab again shows the next match. It saves typing and prevents spelling mistakes.

Changing drive

cd does not switch drives by itself. Type the drive letter and a colon to change drive, or add /d to do both at once.

Names with spaces

Put the path in double quotation marks.

Making folders with mkdir

mkdir creates any missing folders along the way, so the second command made both 2026 and november. The short form md does the same.

If the folder already exists, the command says so and does nothing.

Removing folders with rmdir

rmdir, or rd, removes an empty folder.

The last command was refused: photos has files in it. That refusal is a safety feature.

Danger. rmdir /s foldername removes a folder with everything inside it, including all its subfolders. It asks once, and /q switches even that question off. Nothing goes to the Recycle Bin. Check the name and the current folder twice before using /s, and never run it on a path you typed from memory.

pushd and popd

When you need to visit another folder briefly and come back, pushd folder goes there and remembers where you were, and popd returns.

Opening File Explorer here

start . opens the current folder in a File Explorer window. Going the other way, typing cmd in File Explorer's address bar and pressing Enter opens a Command Prompt in that folder.

Common mistakes

  • "The system cannot find the path specified." The folder name is misspelt, or it is not inside the folder you are in. Run dir /ad to see what is there.
  • Forgetting /d or the drive letter when the target is on another drive. The prompt stays where it was.
  • Forward slashes. Many commands accept them, but they are also how switches begin, so backslashes are the safe choice in paths.

On Linux and the Mac, the matching commands are cd, pwd, mkdir and rmdir.
