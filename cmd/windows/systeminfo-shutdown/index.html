Windows commands

systeminfo, ver, whoami and shutdown: about this computer

A handful of commands report on the computer itself: which version of Windows it runs, what it is called, who is signed in. One more, shutdown, turns it off or restarts it, at once or after a delay.

These were not run for this page, because the answers would describe a real computer. The sample outputs are illustrations.

Which Windows is this?

The number is the build. Windows 11 version numbers still begin with 10.0. The build tells them apart: builds from 22000 upwards are Windows 11.

winver opens a small window with the same information in friendlier words.

systeminfo

It takes a few seconds and prints a page of facts: the Windows edition and version, when it was installed, when the computer last started, the maker and model, the processor, the amount of memory, the network cards and the updates installed.

Who and where

whoami prints the computer name and the account you are signed in with. hostname prints the computer's name alone. whoami /groups lists the groups the account belongs to, which shows whether it is an administrator.

Disks

This older command lists each drive with its size and free space in bytes. On recent versions of Windows, wmic may not be installed. PowerShell's Get-Volume gives the same information in a neater form.

shutdown

shutdown needs a switch saying what to do.

CommandEffect
shutdown /sshut down after a short warning
shutdown /rrestart
shutdown /lsign out
shutdown /hhibernate
shutdown /aabort a shutdown that is counting down
shutdown /s /t 0shut down immediately
shutdown /r /orestart into the advanced start-up menu

/t sets the delay in seconds. Without it, the default is thirty seconds for /s and /r.

Restarting properly

Since Windows 8, an ordinary Shut down from the Start menu does not fully stop Windows. A feature called Fast Startup saves part of the system to disk to start more quickly next time. A Restart does a full reload. When a computer is misbehaving and someone advises restarting it, use Restart, or shutdown /r, not Shut down and power on.

Repair commands you may be told to run

Two commands appear often in troubleshooting advice. Both need a Command Prompt opened as administrator.

  • sfc /scannow checks Windows' own system files against known good copies and replaces damaged ones. It takes a while and is safe to run.
  • chkdsk C: reads the disk's structure and reports problems without changing anything. With /f it also repairs them, which on the Windows drive means it is scheduled for the next restart and can take a long time.

Danger. Do not interrupt chkdsk /f or /r once it has started repairing, and do not run it on a disk that is making unusual noises or failing. Copy your files off a failing disk first. Repair comes second.

Help for any command

help lists the built-in commands, and command /? explains one. Both are on the computer and need no internet.
