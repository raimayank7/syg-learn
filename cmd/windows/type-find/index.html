Windows commands

type, more, find and findstr: read and search text files

Text files, logs and CSV files can be read and searched without opening an editor. type prints a file. more shows it a screen at a time. find and findstr pick out the lines that contain a word.

type: print a file

type is for text. Used on a picture or a program, it prints nonsense and may beep.

more: one screen at a time

For a long file, more pauses after each screenful. Press Space for the next screen, Enter for the next line and Q to stop.

It also works on the output of another command, joined with a pipe, the | sign: dir /s | more.

find: lines that contain some text

find needs the text in double quotation marks, then the file name.

Its switches:

SwitchEffect
/iignore capital and small letters
/vshow the lines that do not contain the text
/ccount the matching lines instead of showing them
/nshow line numbers

Counting lines in a file is a common trick: find /c /v "" counts the lines that do not contain nothing, which is all of them.

findstr: a stronger search

findstr does everything find does and more. It needs no quotation marks for a single word, searches several files at once, and understands patterns.

Note the second command. With several words in the quotation marks, findstr finds lines containing any of them. To search for the exact phrase, add /c:.

Searching many files

Give a wildcard, and each matching line is shown with its file name.

/s searches the files in subfolders too, and /m lists only the names of files that contain a match.

Useful findstr switches

SwitchEffect
/iignore case
/nshow line numbers
/ssearch subfolders
/mprint only the names of matching files
/vshow lines that do not match
/c:"text"search for the exact phrase
/bmatch only at the beginning of a line
/ematch only at the end of a line
/rtreat the text as a pattern (regular expression)

Patterns

With /r, a few symbols have special meaning: . is any character, * repeats the previous character, ^ is the start of a line, $ the end, and [0-9] any digit.

That shows the lines whose time is between 09:05 and 09:07.

Searching the output of a command

A pipe sends one command's output into another. Searching a long listing is the usual use.

The same idea filters the output of any command: tasklist | findstr /i chrome or ipconfig | findstr IPv4.

Saving the result

Send the matches into a new file with >.

sort

sort puts the lines of a file in alphabetical order, and /r reverses it.

find or findstr?

Use findstr. It is more capable and needs less punctuation. find remains useful for its /c count, and you will meet it in older batch files.

On Linux and the Mac, the matching tools are cat, less, head and tail and grep.
