Windows commands

tree and attrib: see folder structure and file attributes

Two small commands that answer questions File Explorer makes awkward: what does this whole folder look like, and why is this file hidden or impossible to change?

tree: a picture of a folder

tree draws the folders inside the current one as a diagram.

The first two lines name the disk. The diagram starts at the dot, which stands for the current folder.

By default it shows only folders. Add /f to include the files.

The /a switch draws the lines with ordinary characters, which copy and print reliably. Without it, tree uses line-drawing characters that some programs show as odd symbols.

Give a path to draw another folder: tree /f /a photos.

attrib: file attributes

Every file carries a few on-off markers called attributes. attrib shows them.

The letters in the left margin are the attributes that are switched on.

LetterAttributeMeaning
Rread-onlyprograms should not change or delete the file
Hhiddennot shown in ordinary listings
Ssystembelongs to Windows; hidden even more firmly
Aarchivechanged since it was last backed up

Most ordinary files show just A.

Setting and clearing attributes

A plus sign switches an attribute on. A minus sign switches it off.

The delete was refused, because the file is now read-only. Clearing the attribute allows it again.

Hiding a file

After +h, the plain dir no longer lists the file, but dir /a does. Hiding is a convenience, not security. Anyone can show hidden files with one setting in File Explorer or one switch on dir.

A whole folder

/s applies the change to matching files in all subfolders, and /d includes the folders themselves.

This form is well known for recovering files on a USB drive that a virus has hidden. If the files on a pen drive seem to have vanished while the used space is unchanged, they have usually been given the hidden and system attributes. On the drive, attrib -h -r -s /s /d *.* makes them visible again. Scan the drive with antivirus software as well, since something set those attributes.

Danger. Do not clear the system and hidden attributes across your Windows drive. Windows hides certain files so that they are not moved or deleted by accident. Use these commands on your own data folders and removable drives.

Why is a file read-only?

  • It was copied from a CD or DVD, where everything is read-only.
  • Someone set the attribute to protect it.
  • It came from an email attachment or a download that a program marked that way.

Clearing the attribute with attrib -r is all that is needed. If you still cannot change the file after that, the cause is permissions, not attributes, and the Security tab of the file's Properties is the place to look.

The archive attribute

Windows switches A on whenever a file is created or changed. Backup programs can copy only the files that have it and then switch it off, so that the next backup takes only what changed since. xcopy /m works this way.

On Linux and the Mac, files have permissions instead of attributes. See chmod.
