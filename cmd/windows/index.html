Windows commands

The commands of the Windows Command Prompt, grouped into pages by what they do. Each page shows the command at work in a practice folder, with the output it really produced.

  • dir: list the files in a folderThe dir command lists files and folders in the Windows Command Prompt. Learn its output, the useful switches /b /s /a /o, wildcards and saving a list.
  • cd, mkdir and rmdir: move between folders and make themMove between folders with cd, create them with mkdir and remove them with rmdir in the Windows Command Prompt, with paths and drive letters explained.
  • copy, move and ren: copy, move and rename filesCopy files with copy, xcopy and robocopy, move them with move and rename them with ren in the Windows Command Prompt, with safe examples.
  • del: delete filesThe del command deletes files in the Windows Command Prompt without the Recycle Bin. Learn its switches, how wildcards behave, and a safe routine.
  • type, more, find and findstr: read and search text filesShow a text file with type and more, and search inside files with find and findstr in the Windows Command Prompt: switches, patterns and pipes.
  • tree and attrib: see folder structure and file attributesDraw a folder's structure with the tree command and view or change hidden, read-only and system attributes with attrib in the Windows Command Prompt.
  • ipconfig, ping and tracert: check your networkFind your IP address with ipconfig, test a connection with ping and trace the route with tracert in the Windows Command Prompt. Reading the output.
  • tasklist and taskkill: see and stop running programsList running programs with tasklist and close a frozen one with taskkill in the Windows Command Prompt: by name or PID, filters, and the cautions.
  • echo, set and PATH: variables in the Command PromptPrint text with echo, read and set environment variables with set, and understand the PATH variable in the Windows Command Prompt, with examples.
  • systeminfo, ver, whoami and shutdown: about this computerFind out about a Windows computer with systeminfo, ver, hostname and whoami, and shut down, restart or schedule a shutdown with the shutdown command.
  • Batch files: put commands in a file and run themWrite a Windows batch file step by step: echo, variables, if, for loops, pause, comments and a small backup script, with safety rules for .bat files.

Where to begin

Read them roughly in this order.

  1. dir lists what is in a folder. Nothing can go wrong with it.
  2. cd, mkdir and rmdir move you between folders and make new ones. This page also explains paths and drive letters.
  3. copy, move and ren do what dragging does in File Explorer.
  4. type, find and findstr read text files and search inside them.
  5. del deletes. Read the whole page before using it. The Command Prompt has no Recycle Bin.

After those five, the rest can be read as needed: tree and attrib for folder structure and hidden files, ipconfig and ping when the internet misbehaves, tasklist and taskkill for a frozen program, echo, set and PATH for variables, systeminfo and shutdown, and batch files for saving a sequence of commands.

Things every Windows command shares

  • Help is built in. Put /? after any command to see its options: copy /?.
  • Options start with a slash, as in dir /b.
  • Capital and small letters do not matter in commands or file names.
  • Names with spaces need double quotation marks.
  • Ctrl + C stops a command that is running.
  • The up arrow recalls earlier commands, and Tab completes file names.

Opening the Command Prompt

Press the Windows key, type cmd and press Enter. To open it already in a particular folder, type cmd in the address bar of a File Explorer window showing that folder.

"Run as administrator" gives a Command Prompt that can change system settings and protected files. Do not use it for everyday work. A mistake there has more room to do harm.
