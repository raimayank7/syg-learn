Windows commands

copy, move and ren: copy, move and rename files

These commands do from the keyboard what dragging does in File Explorer. They are quick for single files and far quicker than the mouse for groups of files chosen by a pattern, such as "every .txt file".

copy

copy takes a source and a destination.

The first command made a copy under a new name in the same folder. The second put a copy into the folder old, keeping the name.

Wildcards copy several files at once.

Danger. If a file of the same name is already at the destination, copy asks before replacing it when you type the command yourself, but not when the command runs inside a batch file, and not if you add /y. Replacing a file destroys the old one. There is no Recycle Bin for this.

What copy cannot do

copy handles files, not folders. Given a folder name as the source, it copies the files directly inside and ignores subfolders. For whole folders, use xcopy or robocopy.

xcopy: folders and all

  • /e copies all subfolders, including empty ones.
  • /i tells xcopy that the destination is a folder, so that it does not stop to ask.

Other useful switches: /d copies only files newer than those already at the destination, /h includes hidden files, and /y stops it asking before overwriting.

robocopy: for serious copying

robocopy, short for robust copy, is the tool for backups and large folders. It can resume after an interruption, copy only what has changed, and write a log.

The order is source folder, destination folder, then options. /e includes subfolders. Run again later, it copies only new and changed files.

Danger. robocopy /mir makes the destination an exact mirror of the source. That means it also deletes from the destination anything that is not in the source. Pointed at the wrong folder, it can empty it. Add /l first: that lists what would happen without doing anything.

move

move takes a file from one place and puts it in another. The original is gone from where it was.

Giving a new name at the destination moves and renames in one step. move also renames folders.

Like copy, move asks before overwriting when typed by hand, and /y suppresses the question.

ren: rename

ren changes the name only. It cannot move a file to another folder, so the new name must not include a path.

Wildcards rename in bulk. This changes the ending of every .txt file to .bak:

Changing a file's ending does not change what is inside it. A text file renamed to .jpg is still text, and will not open as a picture.

Names with spaces

Any name containing a space needs double quotation marks, or the command treats it as two names: copy "annual report.txt" backup.

Checking before a bulk change

Before copying, moving or renaming with a wildcard, run dir with the same pattern. It shows exactly which files the pattern matches.
