A mind map for a group project

A group project goes better when everyone can see the whole plan. A map shows it on one page. These are our own suggestions.

Set it up

  1. Put the project name in the middle.
  2. Make four main branches: Goal, People, Steps, Show (the starter map "project" has these).
  3. Under Goal, write what you are making and who it is for.
  4. Under People, write each person and the job they agreed to do.
  5. Under Steps, write the stages in order and a date next to each.

Rules that help

  • One person keeps the map. Others tell that person what to change, so there is only one copy.
  • Save the map file after each meeting, and name it with the date.
  • Print the map and bring it to the next meeting.
  • Delete finished steps only when everyone agrees.

Sharing the map

This site has no accounts, so a map is shared by sending a picture or the saved map file. The other person opens the file with the Open map file button on the home page. Pictures in PNG or SVG are for reading; the map file is for editing.

When it grows

A map holds up to 150 ideas. If yours is getting crowded, give each big step its own map and link them by name.

The advice on this page is our own. It is not a rule from a school, a board or a publisher, and this site is independent and is not connected with any of them. Your map stays in your own browser: nothing you write is sent to us.
