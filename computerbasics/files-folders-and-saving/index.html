Computer Basics

Files, folders and saving your work on a computer

Everything you keep on a computer is a file: a letter, a photo, a song. Folders are like cupboards or drawers that hold files so that you can find them again.

Saving a file

  1. Choose Save, or press Ctrl + S.
  2. The first time, the computer asks for a name and a place. Type a clear name, such as "Electricity bill March".
  3. Choose a folder you will remember, for example Documents, and press Save.

After that, pressing Ctrl + S saves your changes under the same name. Do it often. If the power goes off, work that was not saved can be lost.

Choosing names

A good name tells you what is inside and when. "Photo" tells you nothing; "Grandson birthday 2026" does. Avoid using the same name for different things.

Where did my download go?

A file you download from the internet is usually put in a folder called Downloads. Your browser also shows a list of recent downloads, and you can open the file from there. If you cannot find a file, use the search box in the file window and type part of its name.

Deleting, and getting back

On a Windows computer a deleted file usually goes to the Recycle Bin first. It stays there until the bin is emptied, so you can often get it back by opening the bin, right-clicking the file and choosing Restore. Once the bin is emptied, the file is gone, so look before you empty it.

Make a second copy

Computers break, get lost and get stolen. Keep a second copy of anything you could not bear to lose, such as family photos, on a pen drive or an external drive, kept in a different place from the computer. Look at it now and then to make sure that it still opens.
