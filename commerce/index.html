Journal, ledger and trial balance tool

Type your journal entries below and the ledger accounts and the trial balance are worked out as you type. If an entry does not balance, or the trial balance does not agree, the tool says so plainly and shows by how much. It starts with a sample set of ten transactions of a made-up trader so you can see how it works; press Clear all and type your own.

How to use it

  1. Write the entry number, then the account names, then the amount in Debit or Credit. Leave the entry number empty on the next line to continue the same entry (a compound entry has three or more lines).
  2. Use the same name for the same account each time. Capital letters and extra spaces do not matter, but a different spelling makes a different account, and the tool will show it as a separate line.
  3. Read section 1: every entry must have equal debits and credits. Fix any entry marked NOT balanced.
  4. Read section 2, the ledger accounts, to see how each account moved, and section 3, the trial balance.

What the tool does not do

  • It does not decide which account to debit or credit. That is the skill you are practising: see debit and credit rules.
  • It does not use your board's format for the journal or ledger. The layout here is a plain one; follow the layout your examiner expects when you write answers.
  • Equal totals prove only that debits equal credits, not that every account is right: read mistakes a trial balance cannot catch.

All names, businesses and figures on this site are made up. This site teaches only the universal double-entry method: every transaction has equal debits and credits, and assets equal liabilities plus capital. Boards, universities and accountancy bodies set their own formats, terms and rules, so always follow the format your own course or examiner asks for. We state no tax rule, rate or limit.
