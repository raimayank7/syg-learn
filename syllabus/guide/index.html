Guides to using a syllabus

How to read the Board's files, where to find them, and how to turn a marks table into a plan.

A syllabus is the most useful free document a student has, and the least read. It says exactly what can be asked and how much each part is worth. These short guides explain how to get the most from it. They are written around the CBSE files for 2026-27 that this site summarises, and the examples in them come from those files.

Start with how to read a syllabus file if you have never opened one. If you already know your way around, go to the page on planning by weightage and then to the planner.

  • How to read a syllabus file
  • Where to find the official syllabus
  • Syllabus, textbook and sample paper
  • Theory, practical and internal marks
  • Planning study time by weightage

Always check the official file. This page is a summary of the CBSE curriculum for 2026-27, made from the subject file on cbseacademic.nic.in, which we read on 12 November 2026. CBSE can revise a syllabus by circular during the year. Before an examination, download the current file from the official site. This is an independent site, not connected with CBSE.
