What Does a Magnet Pick Up?: a school project idea

Test everyday objects to see which are attracted to a magnet.

  • Science
  • Classes 1 to 4
  • About 20 min of work
  • Time to finish: one session
  • Adult needed
An adult is needed. An adult must choose and hold the magnet: use only one large toy magnet and never small strong ones, which are dangerous if swallowed. Please read all the steps before the child begins.

What this project shows

To find out which materials a magnet attracts.

What you need

You needHow many
Large toy magnet1
Everyday objects (spoon, key, foil, eraser, paper clip, wooden stick)8
Plain paper sheet1
Pencil1

Steps

  1. An adult chooses the magnet. Put the objects in a row on the table.
  2. Hold the magnet near each object in turn. See whether the object jumps towards the magnet.
  3. Put the objects that stick in one pile and the ones that do not in another.
  4. Draw two circles on the paper, label them "sticks" and "does not stick", and draw each object in the right one.

What to observe and write down

Look at what the objects that stick have in common. Write a sentence that starts: "The magnet picks up things that are made of...".

How it works

A magnet attracts objects made of iron and a few other metals, such as steel. It does not attract paper, wood or plastic. Not every metal sticks, and some coins and spoons behave differently, so test them and write what you find.

Presenting it

Let your audience guess before you test each object. Never use small, strong magnets, which are dangerous if swallowed.
