Classroom routines that save time: turns, seats and timers

Routines save time because the class already knows what to do. These are our own suggestions; use what suits your class.

Fair turns

Use the name picker for questions, reading aloud and jobs. Because nobody comes up twice before everybody has, children stop asking "why always them?". Tell the class how it works once.

Seats

  • Keep one seating chart for ordinary lessons and a different mix for group work.
  • Print the chart and keep a copy for a substitute teacher.
  • Move children with sight or hearing needs by hand.

Timed activities

A visible clock makes a task feel real. Put the timer on the board in full screen and tell the class what they must have finished when it ends. Use short times for a warm-up and longer ones for work.

A quiet start

Start each lesson with the same two-minute task on the board, so that children settle while you take attendance. A timer set for two minutes marks the end.

The end of the lesson

Keep two minutes at the end for one question: what is one thing you learnt, or one thing that is still unclear? Pick three children with the name picker to answer.
