Random name picker: pick a student without repeats

Type your names and press Pick. Nobody repeats until the round is finished.

How to use it

  1. Type or paste the names, one on each line.
  2. Press Pick a name. The name shows in large letters.
  3. Keep pressing. Each name comes up once in a round; when the round ends, the next press starts a new round.
  4. Press Start again if you change the list.

Why no repeats

A picker that chooses at random every time will sometimes pick the same child twice in a row and miss others for a long time. This one shuffles the whole list and goes through it, so everybody gets a turn before anyone gets a second. At the start of a new round it will not begin with the name that finished the last one.

Using it well

  • Ask the question first, then pick, so that everybody thinks.
  • Let a child say "pass" once and come back to them.
  • Use it for turns and jobs as well as questions: who reads, who erases the board, who leads the line.
