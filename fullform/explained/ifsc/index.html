IFSC full form: Indian Financial System Code

How to say it: letter by letter.

IFSC stands for Indian Financial System Code. It is an 11-character code that identifies one particular bank branch for electronic money transfers in India.

How to read it

Take SBIN0001234 as a pattern.

  • The first four characters are letters and name the bank: SBIN is State Bank of India.
  • The fifth character is always the digit 0. It is kept for future use.
  • The last six characters identify the branch. They are usually digits but can include letters.

Where it is used

You need the IFSC of the receiving branch, along with the account number and the account holder's name, to send money by NEFT, RTGS or IMPS. UPI payments to a UPI ID do not need it.

Where to find it

  • On the cheque leaf, near the branch address.
  • On the first page of the passbook and on account statements.
  • In the bank's app or on its website.

IFSC and MICR

The MICR code is a different thing: a nine-digit number printed in magnetic ink at the bottom of a cheque and used when cheques are cleared. The IFSC is for electronic transfers.

A code can change

When banks merge, the branches of the old bank are given new codes of the new bank, and the old codes stop working after a period. If a transfer fails with a message about an invalid IFSC, ask the receiver to check the current code. Our sister site IFSC Codes lists current and old codes.
