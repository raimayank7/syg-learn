Fixing mistakes in code: what each message means

A mistake in code is called a bug, and finding it is called debugging. Every programmer does it all the time. This page lists what the maker says for common mistakes: they are the real messages from the page.

What was typedWhat the maker says
fowrd 100
Line 1: I do not know the command 'fowrd'. Did you mean 'forward'?
forward
Line 1: 'forward' needs a number, like: forward 100.
forward 5000
Line 1: 'forward' needs a whole number from 0 to 1000, like: forward 100.
colour red
Line 1: I do not know the command 'colour'. Did you mean 'color'?
color pinkish
Line 1: I do not know the colour 'pinkish'. Try: black, red, orange, yellow, green, blue, purple, pink, brown, gray.
repeat 4
forward 10
Line 1: 'repeat' has no 'end'. Add a line with 'end' after its steps.
end
Line 1: 'end' has no 'repeat' to close.

A calm way to debug

  1. Read the message together. It names the line, and the maker selects that line.
  2. Ask "What did you want this line to do?"
  3. Change one thing and run again.
  4. If the picture is wrong but there is no message, run the steps by hand with a finger on the screen, like the turtle.

The hint

If a word is close to a real command, the maker suggests it, like "Did you mean forward". Typing mistakes are the most common bug of all.

For adults

Resist fixing it yourself. Ask questions instead. A bug that your child finds teaches more than ten you find for them.
