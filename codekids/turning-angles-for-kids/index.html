Turning angles for kids: which turn draws which shape

To draw a shape with equal sides, the turtle turns the same amount at each corner. When it has gone all the way round it has turned once, which is 360 degrees. So the turn is 360 divided by the number of sides.

A puzzle: seven sides

360 divided by 7 is not a whole number, and this turtle turns by whole degrees only. If we try 51 degrees, seven times, the turtle turns 357 degrees in all, finishes facing 357 degrees, and ends about 3.6 steps away from where it began (with sides of 60). So the shape does not quite close. That is a good talking point: what would you need to do to fix it?

Use it

  1. Pick a number of sides from the table.
  2. Write: repeat sides, forward 60, right (the turn), end.
  3. Run it and check the shape closes.
repeat 8
  forward 60
  right 45
end

The star

The five-point star turns 144 degrees, not 72. Five turns of 144 make 720, which is two whole turns. Try it and see.
